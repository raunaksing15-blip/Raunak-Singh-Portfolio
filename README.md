# Raunak Singh: portfolio and resume

A static portfolio site and four resume files, all generated from one data file,
`content/profile.json`. The site has **no runtime dependencies and no `npm install`
step**. It needs only Node 18+ to build, and Python 3 if you want to regenerate the resumes.

## Quick start

```bash
node scripts/build.mjs     # build the site into dist/
node scripts/serve.mjs     # preview at http://localhost:4173
node scripts/check.mjs     # static checks (links, anchors, alt text, placeholders, secrets)
```

or `npm run dev` / `npm run build` / `npm run check` if you prefer npm scripts (they only call the same files).

## What is in here

```
content/profile.json      the single source of truth (site and resumes both read it)
src/styles.css            design system and animation
src/main.js               small enhancements: menu, nav highlight, progress line, copy email
src/assets/               photo, fonts (self-hosted), resume PDFs
scripts/build.mjs         renders dist/index.html from profile.json
scripts/serve.mjs         tiny local server
scripts/check.mjs         static checks
tools/resume/             Python generators for the resume PDF, ATS PDF, DOCX and TXT
vercel.json               build settings and headers for Vercel
.github/workflows/        optional GitHub Pages deployment
dist/                     build output (deploy this folder)
```

## Change your details

1. Edit `content/profile.json`. Resume fields (`summary`, `education`, `projects[].bullets`, `skills`, ...) and site-only fields (everything under `site`) live side by side.
2. Rebuild the site: `node scripts/build.mjs`.
3. Rebuild the resumes: `python3 tools/resume/build_all.py` (needs `reportlab`, `python-docx`, `pillow`). Output lands in `src/assets/`, then rebuild the site again so the new PDFs are copied into `dist/`.
4. Set `site.url` in `profile.json` to your final address once you have one. It switches on the canonical link and Open Graph URL.

To replace the resume only, drop a new `Raunak_Singh_Resume.pdf` (and `_ATS.pdf`) into `src/assets/` and rebuild. The `.docx` and `.txt` stay out of `dist/`; they are for you to send directly.

## Deploy (not done yet, needs your approval and account)

**Vercel:** import the repository. `vercel.json` already sets the build command (`node scripts/build.mjs`) and output directory (`dist`). No environment variables are needed.

**GitHub Pages:** push the repository, then Settings > Pages > Source: GitHub Actions. `.github/workflows/pages.yml` builds and publishes `dist/`.

**Any static host:** upload the contents of `dist/`.

No environment variables or secrets are used anywhere. The site collects no analytics and makes no third-party requests (fonts are self-hosted).

## Design and stack

- Static HTML generated by Node, plain CSS, about 90 lines of vanilla JavaScript. No framework, so there is nothing to keep patched.
- Drafting-sheet identity: cool vellum paper, navy ink, one electric blue (matches the resume). Poppins for headlines and UI, Lora for reading text, both subset to Latin and self-hosted (about 100 KB in total).
- Motion, all of it switched off by `prefers-reduced-motion`: one load sequence in the hero (name rises, then the Mitti AI pipeline diagram draws itself and small dots travel along it), a scroll progress line, section rules that draw in, and a grid highlight that follows the pointer. The diagram shows how Mitti AI works: photo, Gemini API, four outputs.
- Without JavaScript the page is complete; only the "Copy email address" button, which needs it, is hidden.

## Known limitations

- Tested in Chromium only. Not tested in Safari, Firefox or on physical phones.
- External links were checked for correct format, not fetched, because the build environment's network is restricted. Open each link once after deploying.
- The EveryRupee live-demo address ends in `edcuation.html` (a typo in the original file name). If it is renamed in the repository, update the link in `profile.json`.
- The education page of that demo contains a joke image featuring a political figure. Consider removing it before recruiters follow the link.
- The Mitti AI repository belongs to a teammate's account (`shresthgoel77-png/kari-ghar`), and EveryRupee's `package.json` points at the same account. Be ready to explain your part in each.
- Nothing has been pushed, published or deployed from your accounts.
